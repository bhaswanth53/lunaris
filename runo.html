Runo — the database engine for Lunaris

A minimal PDO database client and query builder for PHP. Raw SQL first, optional SQL builder, records and casts, reusable query classes, and transactions. Works as a standalone package or with Lunaris.

Read Runo Docs → View Repository ↗
Terminal 
composer require lunaris/runo
Why Runo

SQL in your hands. Bare-metal utilities when you need them.

Not an ORM — just a thin, predictable layer over PDO.

🗄️

Raw SQL first

DB::prepare()->args()->execute() with named placeholders, typed binding, and a rich result set.

🔍

Query builder

Optional Sql for select, insert, update, delete — where, whereIn, joins, order, limit, and offset.

🧬

Records & casts

Hydrate rows into Record objects with casting for int, float, bool, JSON, and DateTimeInterface.

📦

Query classes

Reusable, testable SQL objects: extend Query, implement sql(), run with execute() or run().

🔒

Transactions

Closure-based and manual transactions with commit/rollback and exception safety.

📊

Metadata

Last insert ID, affected/row counts, and execution time on every Result.

MySQL/MariaDB

Runo currently targets MySQL/MariaDB via pdo_mysql with DSN mysql:host=...;port=...;dbname=...;charset=utf8mb4. PHP 8.0+ required.

Start using Runo

Install the package, initialize the connection, and run your first prepared query.
